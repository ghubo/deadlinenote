# Template Email UI Gmail DeadlineNote

Ini adalah template email visual untuk membalas pesan pengguna DeadlineNote dari akun Gmail personal.

Gunakan file HTML ini:

- `docs/operations/gmail-inquiry-template.html`

Template ini dibuat agar terasa hangat, sederhana, dan cocok dengan gaya DeadlineNote: latar cream, teks gelap, aksen merah, dan nada yang ramah untuk mahasiswa.

## Cara Menggunakan Di Gmail

Gmail personal tidak punya tombol bawaan untuk mengimpor file HTML. Cara paling aman adalah menyalin tampilan email dari browser:

1. Buka `docs/operations/gmail-inquiry-template.html` di browser.
2. Pilih tampilan email yang terlihat, bukan source code HTML.
3. Salin tampilan tersebut.
4. Buka Gmail di komputer.
5. Klik **Tulis** atau buka pesan pengguna lalu klik **Balas**.
6. Tempel template ke isi email.
7. Ganti semua placeholder, seperti `[Nama]`, `[topik]`, `[Tulis balasan kamu di sini]`, dan `[Nama Kamu]`.
8. Ubah atau hapus tombol sesuai kebutuhan balasan.
9. Kirim email percobaan ke diri sendiri sebelum dipakai untuk pengguna.

## Simpan Sebagai Template Gmail

Setelah template visual ditempel dan diedit di Gmail:

1. Klik menu titik tiga **Opsi lainnya** di jendela compose.
2. Pilih **Template**.
3. Pilih **Simpan draf sebagai template**.
4. Pilih **Simpan sebagai template baru**.
5. Beri nama `DeadlineNote - Tanggapan`.

Jika menu **Template** belum muncul:

1. Buka setelan Gmail.
2. Klik **Lihat semua setelan**.
3. Masuk ke tab **Lanjutan**.
4. Aktifkan **Template**.
5. Simpan perubahan.

Bantuan resmi Gmail untuk template: https://support.google.com/mail/answer/14864208

## Tips Penggunaan

- Buat balasan tetap singkat. Layout email akan terasa berat kalau isi pesan terlalu panjang.
- Untuk balasan feedback fitur, pakai bagian "Kalau ada masukan lanjutan" sebagai ajakan follow-up; hapus bagian itu jika tidak diperlukan.
- Template sudah dibuat lebih lega untuk layar kecil, tapi tetap kirim test email dan cek di Gmail mobile sebelum dipakai rutin.
- Pertahankan catatan privasi jika pengguna membahas akun, data, atau isi catatan.
- Hapus tombol jika tidak ada link yang benar-benar perlu dibuka pengguna.
- Hindari gambar besar atau screenshot tambahan di template karena email dari Gmail personal bisa terlihat terlalu ramai.
- Selalu kirim test email setelah mengubah warna, jarak, teks, atau link.
